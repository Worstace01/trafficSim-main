How It Works

🚗
Vehicle Simulation
Spawns and moves multiple vehicles across an intersection grid with realistic flow logic.
🚦
Traffic Light Control
Simulates timed traffic light cycles with green, yellow, and red phases at intersections.
🧯
Intersection Mapping
Renders a top-down intersection map as the simulation grid with directional lanes.
📊
Flow Analytics
Tracks and analyzes vehicle throughput, wait times, and congestion at intersections.

💬 This is a Desktop Application

This simulation runs locally using Python and Pygame — it cannot run in a browser. To run it yourself, clone the repository and execute the main script.
